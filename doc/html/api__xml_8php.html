Description détaillée

Génération de données XML à partir des APIs externes du projet.

Ce fichier expose les données récupérées depuis les APIs JSON (Ghibli, Carburants, Géolocalisation) au format XML via la classe DOMDocument de PHP.

Usage : les fonctions retournent une chaîne XML bien formée, prête à être affichée ou transmise à un parser XML.

◆ getGeolocXml()

getGeolocXml ( )

Génère un document XML avec les informations de géolocalisation du visiteur.

Récupère l'IP du visiteur puis interroge l'API ipinfo.io (JSON), et convertit la réponse en XML.

Structure produite : <geolocalisation> <ip>...</ip> <ville>...</ville> <region>...</region> <pays>...</pays> <coordonnees>...</coordonnees> <organisation>...</organisation> <fuseau_horaire>...</fuseau_horaire> </geolocalisation>

Renvoie
string XML bien formé, ou XML d'erreur si l'API est indisponible

getGhibliFilmsXml ( )

Génère un document XML listant tous les films Ghibli.

Récupère les films depuis l'API Ghibli (JSON), puis les convertit en XML structuré avec DOMDocument.

Structure produite : <films> <film id="..."> <titre>...</titre> <titre_original>...</titre_original> <annee>...</annee> <realisateur>...</realisateur> <score_rt>...</score_rt> ... </film> ... </films>

Renvoie
string XML bien formé, ou XML d'erreur si l'API est indisponible
