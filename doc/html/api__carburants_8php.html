Description détaillée

Interaction avec l'API officielle des prix des carburants.

Source : https://data.economie.gouv.fr/api/explore/v2.1/catalog/datasets/ prix-des-carburants-en-france-flux-instantane-v2/records/

L'API retourne des enregistrements JSON. Chaque enregistrement correspond à une station service avec ses prix pour différents carburants.

◆ normaliser_stations()

normaliser_stations ( array $records,
string $carburant = '' )

Normalise les enregistrements bruts de l'API en un tableau uniforme.

Extrait pour chaque station :

  • son nom, adresse, ville
  • ses prix par carburant (SP95, SP98, E10, E85, Gazole, GPLc)
  • ses services disponibles

Si un filtre carburant est précisé, ne garde que les stations proposant ce carburant.

Paramètres
array$recordsTableau brut des enregistrements API
string$carburantFiltre carburant (vide = tous)
Renvoie
array<int, array> Tableau de stations normalisées

recuperer_stations ( string $ville,
string $dept,
string $carburant = '' )

Récupère les stations service et leurs prix depuis l'API gouvernementale.

Construit la requête selon les paramètres fournis (ville, département, carburant), appelle l'API, puis normalise les résultats.

Paramètres

Renvoie
